# 模型请求敏感字段验证

对 FancyU FastAPI 的真实 `POST /v1/chat` 路径运行 24 个合成场景。测试使用 FastAPI 路由、服务 JWT 验证、意图规划、Java 查询客户端及模型适配器；Java 返回数据和模型响应由 HTTP 内存传输提供。模型适配器实际构造和序列化的请求由测试捕获，所有样例数据均为合成内容。

| 结果 | 修复前（`1cbb16f`） | 修复后 |
|---|---:|---:|
| 通过全部断言的场景 | 14/24 | **24/24** |
| 捕获到敏感标记的场景 | 9/24 | **0/24** |
| 捕获到模型请求的场景 | 16/24 | **12/24** |
| 没有发起模型请求的场景 | 8/24 | **12/24** |

修复前，允许外发的意图会把用户原文和完整查询结果放入模型提示词。修复后，提示词中的问题由服务端按意图生成，查询结果仅序列化允许的整数计数，以及性别、校区、年级的预设类别和对应计数。校区用例覆盖实际问卷选项，例如广州海珠南校、深圳校区和广州白云三元里，也保留历史枚举值的兼容测试。格式异常的计数和无可用预设类别的分布查询走本地格式化。

12 个允许场景均捕获到一条模型请求，且合成聚合值完整保留、模型返回的固定回答被采用。其余 12 个场景覆盖个人查询、非允许分布、畸形聚合数据、显式拒绝和认证失败，均未形成模型请求。测试在捕获的请求中查找预埋的身份联系信息、凭据、照片、昵称、标题、自定义类别和原始用户输入，同时检查服务 JWT 是否进入模型请求。结果衡量这些合成样例上的外发边界。

在 `apps/ai-service/` 安装开发依赖后运行：

    python -m eval.run_outbound_privacy --output outbound-privacy.json
    python -m pytest -q tests/test_outbound_privacy.py
